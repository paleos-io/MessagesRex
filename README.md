# MessagesRex

Messages Rex is a privacy-minded Android SMS/MMS client built for a deliberately narrow job: carrier messaging without app-level internet traffic, telemetry, or cloud accounts. It stays on the telephony lane and does not pretend carrier SMS/MMS is end-to-end encrypted. Instead, it hardens the client, protects local security state with a SQLCipher-encrypted database and Android Keystore-backed keys, and gives you understandable control over what reaches your device.

Secure MMS is policy-first. PaleosWapPushReceiver validates each carrier notification before retrieval, then applies per-conversation controls, manual-download mode, per-SIM roaming rules, media-class choices, and hard extension blocks. Choose whether images, video, audio, text, documents, composite MMS, and headerless carrier MMS may download automatically. Approved items use Android’s telephony download path; blocked or deferred items remain local prompts. Internal MMS completion components are non-exported, reducing callback-spoofing exposure.

Messages Rex protects the screen and decoder surface, too. Screenshot blocking uses Android FLAG_SECURE against standard screenshots and recordings; overlay blocking reduces tapjacking on Android 12+. A permissionless isolated decoder contains failures away from the main process when used for supported image handling. AMR/3GP stripping, ADB-injected-message blocking, app-lock controls, and an offline-first design create a messaging client that favors boundaries, visibility, and fewer surprises.
